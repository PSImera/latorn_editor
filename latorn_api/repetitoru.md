## Карточки учащихся

Репетиторский контур отделён от обычных зачислений на курсы. Карточка хранит личные заметки, ставку, предмет и контактные данные. Явный выбор зачисленного пользователя при создании занятия может создать связанную карточку автоматически.

## Групповое занятие

В одном занятии можно указать до 50 участников. Порядок сохраняется, а цена фиксируется отдельно для каждого участника:

```json
{
  "studentIds": ["student-card-1", "student-card-2"],
  "startsAt": "2026-07-20T15:00:00.000Z",
  "endsAt": "2026-07-20T16:00:00.000Z",
  "title": "Разбор пробного варианта"
}
```

После создания начислений нельзя менять состав, цены и статус занятия. Ошибка исправляется отдельной корректировкой.

## Ручной финансовый журнал

Журнал не принимает деньги и не связан с платёжным провайдером. Преподаватель вручную фиксирует фактические операции: `PAYMENT`, `CHARGE`, `REFUND` и `ADJUSTMENT`. Записи неизменяемы.

## Банк заданий

Элемент банка — шаблон, а не живой шаг курса. При вставке в урок создаётся независимая копия, которую можно менять без влияния на источник. Размещаемая копия всегда проходит строгую проверку блока шага.

`POST /api/instructor/task-bank/placements` принимает урок и список шаблонов. В ответе возвращаются созданные шаги и происхождение каждой копии.
