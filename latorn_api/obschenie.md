## Маршруты раздела

| Метод | Маршрут | Доступ | Назначение |
| --- | --- | --- | --- |
| `GET` | `/api/comments` | Доступ к курсу | Получить обсуждение шага. |
| `POST` | `/api/comments` | Доступ к курсу | Создать комментарий или ответ. |
| `DELETE` | `/api/comments/[id]` | Автор или модератор курса | Скрыть комментарий. |
| `POST` | `/api/comments/[id]/report` | Нужна сессия | Пожаловаться на комментарий. |
| `GET` | `/api/notifications` | Нужна сессия | Получить ленту уведомлений. |
| `POST` | `/api/notifications` | Нужна сессия | Отметить одно или несколько уведомлений прочитанными. |
| `GET` | `/api/course-favorites` | Нужна сессия | Получить избранные курсы. |
| `POST` | `/api/course-favorites` | Нужна сессия | Добавить курс в избранное. |
| `DELETE` | `/api/course-favorites/[courseId]` | Нужна сессия | Удалить курс из избранного. |
| `POST` | `/api/support` | Без входа | Отправить обращение в поддержку. |

## Ветки комментариев

Для корневого комментария передайте только `stepId` и `content`. Для ответа добавьте `parentId`:

```json
{
  "stepId": "step-id",
  "parentId": "comment-id",
  "content": "Спасибо, теперь понятно"
}
```

Пользователь должен иметь доступ к курсу. Ограничение на комментарии возвращает отказ до создания записи.

## Лента уведомлений

`GET /api/notifications` поддерживает фильтр непрочитанных и группирует близкие события. Для отметки одного или нескольких уведомлений передайте их идентификаторы:

```json
{ "ids": ["notification-id"] }
```

Для отметки всей ленты передайте `{ "all": true }`. Переход по ссылке уведомления сам по себе не должен считаться подтверждением чтения — отправляйте отдельный запрос.

## Поддержка

Публичная форма поддержки принимает электронную почту, тему и текст сообщения. Не отправляйте через неё пароли, платёжные реквизиты и правильные ответы к заданиям.
