## Права внутри курса

Права задаются участием в конкретном курсе, а не общей ролью на всей платформе. Основные роли команды:

- `OWNER` — владелец;
- `MANAGER` — управление командой и доступами;
- `EDITOR` — редактирование материалов и комментариев;
- `MENTOR` — сопровождение учащихся;
- `REVIEWER` — проверка работ;
- `ANALYST` — чтение журнала и показателей.

Не показывайте кнопку действия, пока не проверили соответствующее право на сервере. Клиентское скрытие элемента не заменяет проверку API.

## Приглашение учащегося

Адресное приглашение связывается с электронной почтой. Одноразовая ссылка не содержит адреса и закрывается после первого успешного принятия. Пример адресного запроса:

```json
{
  "email": "student@example.com"
}
```

Если учётная запись уже существует, доступ появляется сразу. Иначе создаётся приглашение.

## Журнал

`GET /api/instructor/courses/[id]/gradebook` возвращает учащихся, уроки, шаги и агрегированные состояния попыток. Используйте серверные фильтры курса и урока, а на клиенте не пытайтесь восстанавливать правильность по тексту ответа.

## Рецензирование

Очередь показывает работы `REVIEW`, ожидающие ручной проверки. Публикация рецензии идемпотентно отправляет учащемуся уведомление. Скрытые эталонные ответы остаются только в преподавательском интерфейсе.
