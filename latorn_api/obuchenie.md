## Маршруты раздела

| Метод | Маршрут | Доступ | Назначение |
| --- | --- | --- | --- |
| `GET` | `/api/dashboard/student` | Нужна сессия | Получить сводку кабинета учащегося. |
| `GET` | `/api/submissions` | Нужна сессия | Получить доступные попытки решения. |
| `POST` | `/api/submissions` | Доступ к уроку | Отправить ответ или код на проверку. |
| `GET` | `/api/submissions/[id]/reviews` | Участник проверки | Получить опубликованные рецензии к работе. |
| `GET` | `/api/progress` | Нужна сессия | Получить прогресс по шагам. |
| `POST` | `/api/progress` | Доступ к уроку | Отметить просмотр теории или видео. |
| `POST` | `/api/certificates/course/[courseId]` | Курс завершён | Создать или получить сертификат. |
| `GET` | `/api/enrollments` | Нужна сессия | Получить зачисления текущего пользователя. |
| `POST` | `/api/uploads/review-attachment` | Нужна сессия | Загрузить изображение к работе с ручной проверкой. |

## Отправка решения

Обычный ответ передаётся в `POST /api/submissions`:

```json
{
  "stepId": "step-id",
  "answer": 42
}
```

Для программирования дополнительно используются `code` и `language`. Доступные языки определяются настройками конкретного шага.

Возможные состояния попытки:

- `PENDING` — проверка ещё выполняется;
- `CORRECT` — решение принято;
- `WRONG` — ответ неверный;
- `TIME_LIMIT` — превышено время выполнения;
- `ERROR` — проверка завершилась технической ошибкой;
- `AWAITING_REVIEW` — работа ждёт преподавателя.

## Прогресс

Для интерактивных заданий прогресс обновляется после отправки решения. Для теории и видео используйте `POST /api/progress`:

```json
{
  "stepId": "step-id",
  "isPassed": true
}
```

Пройденный шаг не откатывается последующей неудачной попыткой, а лучший балл сохраняется.

## Работы с ручной проверкой

Шаг `REVIEW` может принимать текст и изображения. Сначала загрузите изображения через `POST /api/uploads/review-attachment`, затем передайте полученные локальные адреса в ответе. Итог и комментарий преподавателя доступны через маршрут рецензий и приходят в ленту уведомлений.
